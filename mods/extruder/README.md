# Assorted Extruder

Adds the extruder, a fueled drill that moves in a straight line. It mines whatever its tools can break and lays blocks from its own slots behind itself as it goes. There is one for every tool material, and each level up is faster, burns less fuel and holds more.

Also included in [Assorted Tech](../tech). Worlds made with Assorted Tech 9.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
