# Assorted Tech

Contains an assorted group of additions based around tech, machines and logic. This includes Assorted Elevators, Assorted Bridges, Assorted Gravity, Assorted Grates, Assorted Extruder, Assorted Sensors, Assorted Redstone, Assorted Alarm, Assorted Fan and Assorted Spikes in one download.

If you only want some of them you can install those mods on their own instead. Your world keeps everything either way.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
