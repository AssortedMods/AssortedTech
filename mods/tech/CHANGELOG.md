# Changelog

## 21.1.0.0

First release for Minecraft 1.21.1, for NeoForge and Fabric. Releases for 1.21.1 are numbered 21.1.x.y, where 21.1 is the Minecraft version.

- Matches Assorted Tech 11.0.1 for Minecraft 26.3
- Includes Assorted Elevators, Assorted Bridges, Assorted Gravity, Assorted Grates, Assorted Extruder, Assorted Sensors, Assorted Redstone, Assorted Alarm, Assorted Fan and Assorted Spikes, each at 21.1.0.0
- Requires Assorted Lib 21.1.0.0
