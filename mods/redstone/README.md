# Assorted Redstone

Adds two redstone torches. The flip flop torch turns on with one redstone pulse and off with the next, so one button works it like a switch. The glowstone torch gives off full light while it is powered and goes dark when it is not.

Also included in [Assorted Tech](../tech). Worlds made with Assorted Tech 9.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
