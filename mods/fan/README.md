# Assorted Fan

Adds a fan that blows mobs, players and items away from it or pulls them in. Right click it to pick the mode and how far it reaches. It runs on its own and a redstone signal turns it off.

Also included in [Assorted Tech](../tech). Worlds made with Assorted Tech 9.x keep everything when you switch to this mod.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
