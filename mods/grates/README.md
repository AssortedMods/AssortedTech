# Assorted Grates

Adds item grates. You can walk on them and mobs stand on them, but anything dropped on one falls straight through. There is an iron grate, a gold grate, a grate for every metal Assorted Core adds and copper grates that weather like any other copper. An axe scrapes a copper grate back and a honeycomb waxes it.

The Iron Item Grate is the metal mesh from Assorted Tech 9.x. Worlds made with Assorted Tech 9.x keep their metal mesh as Iron Item Grates when you switch to this mod.

Also included in [Assorted Tech](../tech).

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
